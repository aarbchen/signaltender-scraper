# SBA Mentor-Protégé (13 CFR 125.9) & Joint Venture Operating Agreement Compliance API

Audits and generates SBA All-Small Mentor-Protégé (13 CFR 125.9) and Joint Venture Operating Agreements (13 CFR 125.8 / 124.513 / 126.616 / 127.506 / 128.402), validating the mandatory 40% Protégé substantive workshare floor, Managing Venturer operational control, Employed Responsible Manager designation, Special JV Bank Account cosignature rules, and 13 CFR 121.103(h) affiliation & ostensible-subcontractor safe harbors.

## Key Capabilities
- **Endpoint**: `POST /v1/generate/mentor-protege-jv-agreement`
- **RapidAPI Host**: `sba-mentor-protege-13-cfr-125-8-joint-venture-api.p.rapidapi.com`
- **Architecture**: 100% Stateless, Zero Payload Retention, Strict Pydantic V2 JSON Schema Enforcement
- **MCP Support**: Included in `@signaltender/mcp-server` and remote Streamable-HTTP `/mcp` (`generate_mentor_protege_jv_agreement`)
