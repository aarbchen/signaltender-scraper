# Cost Accounting Standards (CAS / 48 CFR 9904) Coverage & DS-1 Disclosure Auditor API

Evaluates contractor award history and cost accounting practices under 48 CFR Chapter 99 (FAR Part 30 & FAR 52.230-1 through 52.230-6) to determine Cost Accounting Standards (CAS) exemptions, Modified CAS (CAS 401, 402, 405, 406), or Full CAS coverage (>= $50M threshold), audit CAS 401–420 compliance, draft Form CASB DS-1 (8-Part Disclosure Statement) narratives, and model FAR 52.230-6 General Dollar Magnitude (GDM) cost-impact remedies.

## Key Capabilities
- **Endpoint**: `POST /v1/generate/cost-accounting-cas-ds2`
- **RapidAPI Host**: `govcon-cas-48-cfr-9904-ds1-ds2-disclosure-auditor-api.p.rapidapi.com`
- **Architecture**: 100% Stateless, Zero Payload Retention, Strict Pydantic V2 JSON Schema Enforcement
- **MCP Support**: Included in `@signaltender/mcp-server` and remote Streamable-HTTP `/mcp` (`generate_cost_accounting_cas_ds2`)
